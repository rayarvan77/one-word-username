The brief asks for one word and nothing else: our own make.fun username.
No explanation, no links, no pitch — the handle is the entry.

The entry, one word, 10 characters:

> rayarvan77

## Run it

```sh
python3 main.py
```

The program checks the word (a single word, 1–30 characters), writes it
to `/output/entry.txt`, and prints it.

## Why this handle

- **One word, no padding:** "ray" is the name Ray goes by, "arvan" is his
  own name, and 77 is the number he uses everywhere.
- **Sticks after one look:** short, pronounceable, and clearly a person's
  name rather than a random string.
- **A handle its owner wears happily:** it is the same username Ray uses
  across GitHub and make.fun, not a joke aimed at anyone else.
